# MEMORY

Registro de decisiones técnicas, bugs resueltos y hallazgos no obvios del proyecto.

## Reglas

- **Consulta este archivo antes de empezar cualquier tarea.** Es el único lugar donde se guardan las lecciones aprendidas del proyecto; `AGENTS.md` solo lo referencia.
- Debe actualizarse al terminar cada tarea relevante con una entrada fechada (`YYYY-MM-DD`).
- Sé conciso: una entrada por hito, indicando el problema, la decisión y la verificación.
- No borres entradas anteriores salvo que estén obsoletas; en ese caso corrígelas y deja constancia.
- **Límite estricto: 100 líneas.** Antes de añadir una entrada ejecuta `wc -l MEMORY.md`; si al añadirla se supera el límite, condensa entradas o archiva las más antiguas en `MEMORY-ARCHIVE.md`. Nunca dejes `MEMORY.md` por encima de 100 líneas.

- 2026-11-21 — Fase 3 (confianza en proxies) cerrada sin depender de Render, por decisión del usuario. Evidencia local con test temporal: con `TRUSTED_PROXIES=*` **y** con un proxy explícito, Laravel `$request->ip()` devuelve la **última** IP de `X-Forwarded-For` (`203.0.113.9, 198.51.100.7` → `198.51.100.7`); si el borde antepone la IP real y conserva la enviada por el cliente, gana la falsificada. La declaración pública de Render («we set the first IP in the list to the real client IP») apunta exactamente a ese caso, pero no se usa como supuesto. Solución independiente del proveedor: `TrustedProxyPolicy` rechaza `*` en producción en el arranque HTTP (como CORS) y `ClientIpResolver` es la única fuente de IP para `AuditService`, `LoginFailureAuditor` y las siete claves de limitadores de `AppServiceProvider`. Acepta la cabecera solo si el par está en `TRUSTED_PROXIES` y trae **una sola IP válida**; con varios saltos, IP inválida, par no confiable o `*` usa la IP de la conexión (fail closed). El contrato del edge es sobrescribir `X-Forwarded-For` con una IP; los clientes que envían su propia cadena pierden granularidad por cliente pero no pueden falsificarla. Ojo: no sustituir `$request->ip()` en esos consumidores por accidente; HSTS sigue dependiendo de `TrustProxies` + `X-Forwarded-Proto`, no del resolver. Verificación: 462 tests / 2 872 aserciones en SQLite, PHPStan 0, Pint 372 archivos, `audit` limpio, `TrustedProxyConfigTest` y `TrustedProxyTest` nuevos.
